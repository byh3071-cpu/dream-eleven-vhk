# Goal 3: 전술 지침 반영 + 회귀 테스트

## 배경
"공격적인 축구 / 수비적인 전술을 설정할 수 있게"라는 핵심 요구사항. 지침이 계산에 실제로 반영되지 않으면 장식일 뿐이다.

## 동작
- `src/sim/tactics-modifiers.js` — 멘탈리티(공격/수비 트레이드오프), 압박강도(수비가중+스태미나소모+역습허용), 템포(phase 밀도), 폭(레인 가중) 4개 지침을 duel/possession 계산에 연결
- 공짜 이득 금지 원칙: 한 스탯이 오르면 반드시 다른 쪽이 내려가는 트레이드오프 구조

## Completion Check
- 지침 값을 바꾸면 Goal 2의 몬테카를로 결과 분포가 통계적으로 유의미하게 달라짐을 테스트로 확인
- 극단적 지침 하나가 상대 무관하게 항상 우세하지 않음(회귀 테스트)
