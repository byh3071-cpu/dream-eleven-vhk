# 능력치 확장 — 결정 로그 & 큐레이션 플랜 (라이브)

> 벤치마킹 근거 = `docs/research/player-attributes.md`, 확장 규칙 = `docs/adr/ADR-001`.
> 이 문서는 세션에서 확정된 결정·현재 상태·다음 큐레이션을 **박제한 라이브 문서**(진행하며 갱신).

## 1. 확정된 결정 (locked)

| 항목 | 결정 |
|---|---|
| **스케일** | **1~99 유지** (FM식 1~20 안 씀). 바꾸면 엔진·318테스트·게이트 전부 재보정 = ADR-001 위반. FM에선 능력치 **종류·의미만** 차용, 숫자·표시는 FIFA식 |
| **표시(UI)** | 카드 = **종합(6 롤업)**, 세부 하위스탯 = **숨김 + 상세화면** |
| **확장 방식** | 엔진 주도 additive(ADR-001): "판정 심화 → 그게 읽는 하위스탯" 순서. 빅뱅·장식 금지 |
| **최종 개수** | 미리 못박지 않음. 엔진 소비 기준 **12~16으로 수렴**(20은 슬라이스 더 필요) |
| **composure** | 의미 = **압박 상황 실행 전반**(옵션2). 현재 PK 훅은 임시 → "압박(pressure) 컨텍스트" 엔진 슬라이스 후 광역화 |
| **특화 선수 유형** | 만들기로. 선수 전 포지션(수비·미드·공격·GK) + **감독·코치까지**. (미래 트랙) |
| **프로세스** | 슬라이스마다 결정 확인받고 진행. "정밀하게 깎아가며" |

## 2. 현재 상태 (이미 커밋됨 · master)

| 슬라이스 | 상태 | 커밋 |

## 3. 프로세스 계약 (누가 뭘 정하나)

- **제작자(너)**: 무엇을 / 무슨 의미로 / 뭘 먼저 / 어떤 선수유형 / 손맛(강도). = 큐레이션·우선순위·정체성.
- **나**: 어떻게 안전하게(결정론·마이그레이션·배선·테스트) + 매 슬라이스 앞에서 **결정 지점을 옵션+트레이드오프로 표면화**. 변수명·기계적 배선은 알아서(그걸로 안 귀찮게).

## 4. 능력치 후보 지도 (큐레이션 대상)

핵심 열 = "엔진이 지금 읽나?" — 안 읽히면 쪼개도 장식(ADR-001).

| face(현행 1~99) | 쪼갤 후보 (FM/FIFA 개념) | 엔진 소비 현실 | 난이도 |
|---|---|---|---|
| **physical** | 공중볼(aerial)·몸싸움·스태미나 | aerial **✅완료** / 스태미나=이미 별도 시스템 / 몸싸움=판정 없음 | aerial 끝, 몸싸움만 슬라이스 |
| **shooting** | 결정력(box)·중거리(long)·슛파워·발리·침투 | 박스 vs 중거리 구분이 지금 **연출(narration)에만** → 판정층으로 옮기면 소비 | 🔨 작은 슬라이스 |
| **defending** | 태클·마킹/위치·인터셉트·헤딩 | 태클 vs 인터셉트 구분도 **연출에만** → 판정층 옮기면 소비 | 🔨 작은 슬라이스 |
| **passing** | 숏·롱·비전·크로스·커브·FK | progression·키커선정엔 쓰나, **크로스 "품질"은 판정 입력 없음** | 🔨 크로스 판정 신설 |
| **pace** | 가속(accel)·최고속(sprint) | **듀얼에서 안 읽음**(팀전력 가중·포지션에만) | 🔨 가속 판정 신설 |
| **GK 전용** | 반응·핸들링·커맨드·킥 | 지금 **defending 단일값 재사용**(벤치마크 갭) | 🔨 GK 판정 심화 |
| **dribbling** | 볼컨·드리블·민첩·밸런스·반응·침착 | **전부 progression 한 자리로 수렴** | ⭕ 유지(쪼개도 장식) |

## 5. 진행 순서 (다음 슬라이스)

1. **shooting → 결정력 / 중거리** (작은 슬라이스 · 여우형 vs 원더골형)
2. **defending → 태클 / 위치** (작은 슬라이스 · 파이터형 vs 지능형 수비)
3. **큰 슬라이스**(우선순위 미정): 크로스 품질 · 가속 · GK 전용 세트 · 몸싸움
4. **composure 광역화** — "압박(pressure) 컨텍스트" 엔진 추가 후 (옵션2)
5. **특화 유형 · 감독/코치** — 미래 트랙

## 6. 열린 결정 (네 차례)

- [ ] shooting을 결정력/중거리로 쪼갤지 + 강도
- [ ] 지도에서 뺄/바꿀 항목 있는지
- [ ] 큰 슬라이스(크로스/가속/GK/몸싸움) 우선순위
