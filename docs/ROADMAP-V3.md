## 리서치 결론 1 — 사운드 (2026-07-03 확정)

- **소스 확정: Freesound CC0 필터** — "stadium crowd soccer" CC0 38건 실존, 실제
  경기장 녹음(메스타야/산 시로/브라질 6만 관중). CDN 프리뷰(-hq.mp3 128kbps)는
  로그인 없이 직링크 다운로드 가능(실수신 검증). 게임용으로 충분한 품질.
- 6종 직링크 확보: 앰비언스(39733)/골 함성(528799, 397434)/탄식(494362, 612131)/
  휘슬(538422 단발, 568995 멀티)/킥(555042)/리액션 웨이브(829456). 전부 CC0.
- **탈락**: BBC RemArc(상업 불가 — 유료 앱 배포 계획과 충돌), Kenney(스포츠 사운드
  없음). Pixabay는 라이선스 최상이나 스크립트 다운로드 불가(브라우저 수동 보조용).
- 구현 방식(EA FC 레이어링 차용): 베드 루프 상시(게인 0.3) + 전개 게인 램프 +
  이벤트 원샷(랜덤 피치 ±3% 변형) + 골 순간 스파이크 후 10초 복귀. Web Audio
  AudioBufferSourceNode loopStart/End로 무결절 루프(mp3 패딩 컷).
- 포맷: Opus(webm) 주력 + m4a 폴백, 총 용량 ~2MB. CC0라 크레딧 의무 없음(예의상
  docs/CREDITS.md에 표기).

## 리서치 결론 2 — 실명 선수 라이선스 (2026-07-03 확정)

핵심 사실(교정 2건 포함):
- 이미지 없이 **이름만 써도** 한국 부정경쟁방지법 타목(2022.6 시행)이 성명 자체를
  보호 — "영업을 위한" 사용이면 침해 소지. 무료·무광고 웹은 리스크 낮음, 광고/유료
  앱(스토어)은 높음(스토어 권리침해 신고가 현실 경로).
- 교정①: PES 무라이선스 시절에도 선수 실명은 FIFPro 집단 라이선스 하에 사용(미계약
  선수는 가명 처리). 교정②: FM도 FIFPro와 55개국 naming rights 장기 계약 — "팩트
  데이터라 자유" 통념은 틀림.
- 사망 레전드가 더 안전하지 않음: 펠레 브랜드는 2025년 NR Sports가 인수해 상업 관리,
  마라도나는 생전 Konami 제소 전력 + 유족 분쟁 중 — 집행 동기가 강한 축.
- 개인 무료 웹게임이 실명만으로 제소된 공개 사례는 미발견 — 집행은 규모·수익화
  시점에 발생, 관행은 C&D → 시정 종결.

정책(3단계 — goal 30에 편입):
1. **지금(무료 웹 독푸딩)**: 실명 유지 + 가드레일 — 팬 프로젝트 고지문, 이름 데이터
   단일 파일 분리(즉시 교체 가능 구조), 고위험 인물(펠레·마라도나·손흥민급) 우선
   변형 검토.
2. **수익화/스토어 전 필수**: FM/PES 패턴 — displayName 이중화, 기본 배포는 가상
   변형명, 인게임 리네임 + 이름셋 JSON 임포트/익스포트(유저 사적 편집은 적법).
   IF 모드도 동일 구조(오마주 변형명 + 유저 실명화).
3. **흥행 후 옵션**: FIFPro 등 정식 라이선스 협상(Retro Bowl 경로 — 소규모 취득
   사례 존재). 수익화 직전 변호사 검토 1회 권장.
