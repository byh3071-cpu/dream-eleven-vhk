# PRD — dream-eleven-vhk

## 한 줄 정의
레전드/현역 축구선수로 베스트일레븐을 구성해 감독처럼 포메이션·전술을 짜고 2D로 경기를 시뮬레이션하는 드림매치 게임

## 문제 (Problem)
축구 팬이라면 "지단과 마라도나가 한 팀이면 누가 이길까", "내가 감독이면 이 선수들로 어떤 전술을 짤까" 같은 상상을 흔히 하지만, 이걸 실제로 확인해볼 방법이 없다. 스탯을 비교하는 정적인 비교표는 있어도, 포메이션과 전술 지침이 실제 경기 결과에 어떻게 반영되는지 "감독처럼 판단하고 결과를 지켜보는" 경험을 주는 도구는 없다.

## 해결 (Solution)
레전드+현역 선수 프리셋 DB에서 양 팀(자기팀/상대팀) 11명씩을 직접 선발하고, 포메이션과 전술 지침(공격성·압박·템포·폭)을 설정한 뒤 킥오프하면, 선수 스탯·특성·전술이 실제로 반영된 확률 기반 시뮬레이션 엔진이 90분 경기를 계산하고, 2D 필드 위에서 그 결과를 재생해서 보여준다. 사용자는 두 팀 모두를 구성하는 "감독"으로서 결과를 만들어낸다.

## v1 IN (필수 기능)
| # | 기능 | 설명 | 우선순위 |
|---|------|------|----------|
| 1 | 양 팀 스쿼드 빌더 | 프리셋 선수 DB(레전드+현역, 16~20명 → 이후 60~100명)에서 포지션 슬롯에 11명씩 배정, 자기팀/상대팀 둘 다 사용자가 구성 | P0 |
| 2 | 포메이션 + 감독 지침 | 포메이션 프리셋(4-4-2 등) 선택 + 슬롯 미세조정, 멘탈리티/압박강도/템포/폭 4개 지침을 라벨형 칩으로 설정 | P0 |
| 3 | 매치 시뮬레이션 엔진 | 존 기반 포제션 모델 + 듀얼 판정(Elo식) + 특성(Trait) 훅 + 스태미나로 90분 경기를 사전계산, 몬테카를로 검증 게이트(평균 득점 2.5~3.0골, 강팀 승률 60~75%) 통과 | P0 |
| 4 | 2D 경기 관전 | 사전계산된 이벤트 로그를 DOM 기반 필드 위에서 재생 + 텍스트 커멘터리 병행, 재생/배속/스킵 컨트롤 | P0 |
| 5 | 결과 화면 | 스코어·팀 스탯·이벤트 타임라인, 재대결/스쿼드 수정/새 경기 | P0 |
| 6 | 선수 데이터 확장 | 16~20명(엔진 검증용) → 60~100명(콘텐츠, 코드 변경 없음) | P1 |
| 7 | Canvas 연속 스티어링 렌더러 | DOM 렌더러와 동일 인터페이스로 교체 가능한 업그레이드 렌더러 | P1 |

## v1 OUT (명시적 제외)
- 실시간 상대 AI (양 팀 다 사용자가 사전 구성 — 상대 의사결정 엔진 불필요)
- 경기 중 실시간 전술 변경/교체 (킥오프 전 고정, precompute-then-replay 구조와 충돌)
- 선수 부상, 카드 누적, 연장전/승부차기
- 시즌 모드, 팀 케미스트리, 홈/원정 어드밴티지
- 실사 선수 사진, AI 생성 인물 초상 (저작권 + "AI스러움" 회피 — 이니셜/실루엣 뱃지로 대체)
- 서버/백엔드, 계정 시스템 (localStorage만)

## 화면 인벤토리
| 화면 | 핵심 요소 |
|------|----------|
| 스쿼드 빌더 (홈/원정 공용, `side` 파라미터) | 포메이션 칩, 세로형 필드에 11슬롯, 선수 슬롯 카드(레이팅+포지션+이름+이니셜뱃지), 팀 종합전력 표시, 리스트뷰(검색+포지션 필터) |
| 감독 지침 (홈/원정 공용) | 멘탈리티/압박/템포/폭 4개 지침 칩, 포메이션 미세조정 |
| 매치 프리뷰 | 양팀 라인업 카드 대조, 종합전력 비교, 킥오프 버튼 |
| 경기 관전 | 2D 필드(DOM), 스코어보드, 커멘터리 티커, 재생/배속(1x/2x/4x)/스킵 컨트롤 |
| 결과 화면 | 최종 스코어, 팀별 스탯, 이벤트 타임라인, 재대결/스쿼드 수정/새 경기 버튼 |

## 성공 지표
- 몬테카를로 검증 게이트 통과: 100판+ 시뮬레이션에서 평균 득점 2.5~3.0골/경기, 명확히 강한 팀의 승률 60~75%
- 수동 E2E 1회 완주: 양 팀 구성 → 포메이션/지침 설정 → 킥오프 → 관전 → 결과 확인까지 끊김 없이 동작
- 전술 지침을 바꾸면 결과 분포가 실제로 유의미하게 달라짐 (지침이 장식이 아님을 테스트로 증명)
