# PRD — dream-eleven-vhk

> 제품 요구사항 정본. "무엇을·왜·누구를 위해"를 담는다. 기술 구현은 docs/ARCHITECTURE.md,
> 세계 리그 실행은 docs/world/WORLD-ROADMAP.md, 설계 결정 근거는 docs/DESIGN.md 참조.
> 이 문서는 제작자(백요한) 인터뷰로 의도를 끄집어내 작성됐다.

## 한 줄 정의

**같은 결정론 시뮬 엔진 위에서 "누구의 시점이냐"만 다른 3-모드 축구 인생 시뮬** — 실시간 조작
액션이 아니라 전략·경영·관계·서사로 축구를 사는 게임. 하드코어 시뮬의 깊이 + 축구 만화의 드라마.

## 제품 철학 (심장)

**"FM이 경쟁자가 없어서 멈춰버린 지점을, 유저의 결핍을 기능으로 바꿔서 넘는다."**

풋볼매니저는 감독 시뮬의 사실상 독점이라 정체됐다 — 감독이 연봉을 아무리 벌어도 쓸 데가 없어
그냥 숫자고, 선수와 감독의 관계는 얕은 사기 %에 머문다. 이 게임은 **유저가 실제로 원하지만
채워지지 않은 욕구(돈의 사용처, 존경받는 관계, 상상의 대결)를 끄집어내 실제 기능·모드로 만드는
것**을 최우선 원칙으로 삼는다.

## 비전 (북극성)

神(양 팀 조물주)·감독(구단 운영)·선수(한 인생)의 세 시점이 같은 39개국 세계를 보고, 한 시점에서
남긴 흔적이 다른 시점에 영구히 남는다. 반응속도가 아니라 판단·선택·관계·이야기로 승부하는,
오프라인에서 완결되면서 AI 시대의 재미를 얹은 축구 인생 시뮬레이터.

## 타겟 유저

**핵심 타겟 = 축구/스포츠에 진심인 하드코어 팬** (제작자 자신부터가 그 유저).

| 우선순위 | 세그먼트 | 니즈 |
|---|---|---|
| **1차** | 제작자 본인 + 아는 동생 | 내가 하고 싶은 게임 — 취향이 기준 |
| **1차** | 하드코어 축구 매니아 (에펨코리아 커뮤니티) | FM의 아쉬움을 채운 깊이 + 신선함 |
| 나중 | 넓은 대중 (모바일 라이트) | 접근성 높인 버전 |

## 핵심 차별점 (FM 대비)

1. **결핍 → 기능** — FM이 방치한 유저 욕구를 실제 시스템으로. 아래 "FM이 못 채운 것" 표가 로드맵.
2. **선수-감독 관계의 대리만족** ⭐ — "게임 속 내 감독이지만, 스타 플레이어들이 나를 좋아하고
   존경하는 관계 데이터를 볼 때의 뿌듯함". 얕은 사기 %가 아니라 **수치 + 서사 이벤트**(존경·신뢰·
   사제·배신·재회)로 살아있는 관계. 이 게임의 심장.
3. **돈의 이원화** — 구단 예산(전력)과 감독 개인 돈(명성·영향력)을 분리해 "번 돈을 실제로 쓰는"
   판타지를 연다. 돈이 곧 다음 선택지를 여는 열쇠.
4. **AI 향신료** — IF 편성 도우미·기자회견·영입 협상 대화를 AI로. 오프라인 코어를 해치지 않는
   선택적 레이어(아래 AI 전략).
5. **3-모드 공유 세계 + 크로스모드 지속성** — 내 선수가 은퇴→감독이 되고, 그 흔적이 세계에 남는다.
6. **하드코어 + 드라마 동시** — FM의 숫자 깊이와 축구 만화의 감정선을 한 게임에.

## FM이 못 채운 것 → 우리가 만들 기능 (결핍 지도)

| 결핍 | FM 현재 | 우리가 채울 것 | 우선 |
|---|---|---|---|
| **선수-감독 관계** | 얕은 사기 % | 존경·신뢰·사제·배신·재회의 수치+서사. 스타가 나를 인정, 라커룸 위계·파벌 | ★ 심장 |
| **번 돈의 사용처** | 숫자일 뿐 | 감독 개인 돈 = 명성·브랜드·라이프·사비 후원 (구단 예산과 분리) | ★ |
| **내가 키운 선수** | 스탯만 성장 | 은퇴식 "감독님 덕분에"·회고·내 지도철학 각인 | ○ |
| **떠난 선수 재회** | 거의 없음 | 상대팀으로 만남·복귀·재계약 드라마 | ○ |
| **감독 개인사** | 이름표 수준 | 내 감독의 커리어·명예의전당·라이벌 감독 숙적사 | ○ |
| **빈약한 매치 관전** | 2D 점 | 3D 실감 관전(이미 구현) | ✅ |

### 감독 개인 돈 — 사용처 구상 (돈 = 명성 자본)

구단 예산이 "전력"이라면 감독 개인 돈은 "영향력"이다. **명성 루프**: 성적 → 연봉·보너스 → 명성
소비 → 영향력(오퍼·설득·신뢰) → 더 큰 무대. 돈이 다음 선택지를 여는 열쇠.

| 카테고리 | 쓰는 곳 | 게임 효과 |
|---|---|---|
| 명성·브랜드 | 자서전·방송·광고·다큐 | 명성↑ → 빅클럽 오퍼·연봉 협상력·선수 설득력 |
| 라이프스타일 | 맨션·슈퍼카·요트 | 감독 프로필 위신(선수·팬 반응) |
| 사비 투자 | 유스 사재 후원·스카우트망·개인 코치 | 구단 예산 **밖** 전력 보강 |
| 인맥 | 스타 에이전트·감독 네트워크 | 영입 우선권·이적 정보 |
| 은퇴 후 | 구단 지분 인수·아카데미 설립 | 제2커리어(크로스모드 연결) |

현실성 기준: "감독 돈=명성 / 구단 돈=전력" 분리선까지만 지키고 나머지는 게임적으로 푼다.

### 서사 엔진 — 드라마 생성 (하드코어 + 축구 만화 감성)

라이벌·감동을 데이터 트리거로 생성(오프라인 템플릿 뼈대) + AI 향신료로 대화/기사 살 붙임.
**선수-감독 관계 시스템이 트리거의 핵심 연료**(존경 선수의 헌신 vs 갈등 선수의 반란).

- **라이벌 생성 (14종)**: 자동(지역더비·우승경쟁·강등생존·승격동기) + 역사 누적(이적앙금·배신·
  감독숙적·복수·전소속·왕조도전자·유스경쟁·오심앙금·미디어·팬덤) — 내 세계마다 다른 숙적사.
- **감동 트리거 (20+)**: 사제·언더독·복귀·라스트댄스·재회·충성/배신·데뷔골·고향복귀·극장골·
  개인기록·주장승계·감독첫트로피·구세주·재정위기극복·세대교체·복수전·눈물의방출·월드컵영웅·
  은퇴번복·부자대결.
- **전달 채널 (12)**: 뉴스피드·컷신·기자회견(AI)·선수SNS·감독회고록·시즌다큐·라커룸토크·
  팬레터·라이벌도발·명예의전당·어워드쇼·중계코멘터리.

### 매치 경험 — 실제 축구 같은 관전 (FM 넘기)

핵심 방향: **부드럽고 자연스럽고 실제 축구처럼** + 골 감흥.

- **리얼리즘**: 모캡급 자연스러운 모션(프로 에셋 교체 대비 — 렌더 추상화)·개성 모션(드리블/슛폼
  시그니처)·자연스러운 볼 물리·군집 지능(오프더볼 침투·라인·압박 쉐입)·환경(날씨·주야간).
- **관전 기능**: 전술 가시화·서사 연동(라이벌전 열기)·감독 터치라인 반응·멀티카메라·모멘텀
  게이지·명장면 슬로우·MOTM 실시간·히트맵/패스맵·팀토크 효과·라이벌전 인트로·우승/강등 연출.
- **골 연출**: 선수별 시그니처 셀레브레이션·다각도 리플레이·관중 폭발·해설 고조·특별골(결승/
  데뷔/극장골) 연출.
- **보기 모드**: 하이라이트 압축(FM식) + 1배속 풀 관전 + 빠른 결과+다시보기 — 셋 다 지원.

## 3-모드 상세

두 주력 모드(감독·선수)는 **병렬로** 깊이 만든다(공유 세계라 함께 자람). IF는 재미의 입구.

| 모드 | 시점 | 핵심 루프 | 상태 |
|---|---|---|---|
| **IF (神)** | 양 팀 조물주 | 레전드+좋아하는 선수로 드림팀 편성(AI 도우미) → 11:11 드림매치 관전 → 결과 | ✅ 구현(2D+3D) |
| **커리어 (감독)** | 구단 운영자 | 스쿼드·전술·이적·**재정(구단/개인 이원화)**·유스·**선수 관계** → 시즌 → 왕조·명성 | ✅ 슬라이스 → ▶ world 확장 중 |
| **선수 (개인)** | 선수 '나' | 유스/기성 시작 → 훈련·활약·특성 언락 → 이적·국대·서사 → 은퇴·**감독 전환** | ⬜ 계획(Epic 2) |

### 선수 모드 여정 (인생 시뮬)

- **시작(3)**: 유스 무명(15세 아카데미 흙수저) / 가상 기성(특정 능력) / 커스텀(능력·국적·포지션 배분).
- **성장**: 훈련 포커스(주간 메뉴) + 실전 활약 경험치 + 특성 언락(마일스톤) + 멘토링 + 폼/슬럼프 +
  부상/재활 + 포지션 전환·노쇠 대응.
- **경기(선수 시점)**: 내 선수 카메라 팔로우 + 감독에게 역할·프리롤 받기 + 개인 목표(평점·골) + 동료 케미.
- **인생·서사**: **감독과의 관계(대리만족 대칭 — 감독이 나를 신뢰·주전 기용)** · 이적/오퍼 선택 ·
  계약 협상 · 국가대표·월드컵 · 라이벌 선수 · 시그니처 각인 · 스캔들·사생활 · 팬덤·SNS ·
  원클럽 vs 저니맨 드라마.
- **커리어 아크**: 데뷔→주전경쟁→스타→레전드→노장→은퇴→**감독 전환**(공유세계 화룡점정) +
  발롱도르·명예의전당·은퇴식. 내 시그니처가 크로스모드로 세계에 영구히 남는다.

## AI 전략 (하이브리드 — 오프라인 코어 + 선택적 향신료)

AI 시대에 맞는 재미를 얹되, 게임 근본(오프라인·결정론·의존성0)을 해치지 않게 **레이어 분리**:

| 레이어 | 성격 | 예시 |
|---|---|---|
| **코어 (시뮬·세이브)** | 오프라인·결정론 **불변** | 경기·순위·이적·성장·관계 — 인터넷 없이 완결 |
| **AI 향신료 (선택)** | 온라인, 켜고 끄기 | IF 드림팀 편성 도우미 · 기자회견 대화 · 영입 협상 · 중계 서사 |

**원칙**: AI는 필수 코어가 아니라 **켜는 향신료** — 없으면 템플릿 서사로 폴백(게임 완결), 있으면
풍부. "오프라인 원칙 + 요즘 AI 재미"를 동시에.

## 핵심 기능

### 구현됨
- 스쿼드 빌더 + 감독 지침 · 결정론 매치 엔진(존 포제션/듀얼/특성/스태미나/세트피스) + 몬테카를로 게이트
- 2D(DOM)/3D(Three.js) 듀얼 렌더러 · 3D 스타디움·카메라·절차적 모션·사운드
- 커리어: 드래프트 리그·시즌·순위·득점왕·재정·유스·이적/계약·은퇴·시즌 서사·세이브 마이그레이션

### 계획 (결핍→기능 우선)
- **선수-감독 관계 시스템**(★심장): 신뢰·존경 수치 + 관계도/파벌 맵 + 서사 이벤트 트리거
- **재정 이원화**: 구단 예산(전력) / 감독 개인 돈(명성·브랜드·라이프)
- **world**: 39개국 리그(무제한 나라 구조) + 로스터/시뮬/순위표 + 리그 개성 + 승강 + 월드 세이브
- **선수 모드**: 아바타·훈련 성장·시점 관전·특성 언락·개인 이적/수상·개인 서사·국대·감독 전환
- **크로스모드**: 세계 리졸버로 선수↔감독 지속성
- **AI 향신료**: IF 편성·기자회견·협상 대화
- **비주얼 마감·출시**: 아트 스타일·캐릭터 에셋·PWA·스토어

## UX 원칙

- **판단 > 반응**: 실시간 조작 없음. 경기 전 결정 + 관전.
- **결정론 = 신뢰**: 같은 세이브·시드 = 같은 결과. 재현·공유 가능.
- **재미는 관계·서사에서**: 스탯 나열이 아니라 존경받는 관계·이적 드라마·왕조·개인사.
- **오프라인 우선 + AI 선택**: 인터넷 없이 완결, AI는 켜는 향신료.

## 출시 경로 (커뮤니티 우선)

1. **에펨코리아 반응 테스트** — 데모(IF 드림매치 또는 커리어 한 시즌 압축 + 게임플레이 화면)로
   "이런 축구 게임 만들었다" 글 → 하드코어 팬 피드백 수집(누군가 야구 시뮬을 이렇게 검증한 선례).
2. **웹 무료 공개** — 반응 좋으면 무료 웹으로 접근성 확보.
3. **스팀 프리미엄** (PC 유료) + **모바일 F2P** (부분유료) — 정식 상용화.

## 성공 지표

- **엔진 신뢰성**: 몬테카를로 게이트(평균 2.5~3.0골, 강팀 승률 60~75%), 결정론 재현 100%.
- **차별점 검증**: 선수-감독 관계가 "뿌듯함"을 실제로 주는가(플레이테스트), 돈 이원화가 의미있는
  선택을 만드는가.
- **커뮤니티 반응**: 에펨코리아 데모 글의 실사용자 반응(관심·피드백·재플레이 의향).
- **모드 완결성**: 각 모드 E2E 완주. 크로스모드 참조 무결성. 세이브 마이그레이션 무손실.
- **출시 품질**: 스토어 심사 통과급 비주얼·안정성·라이선스 클린.

## 리스크 / 제약

- **스코프 폭발**: 39개국·3모드는 거대 → 얇은 수직 슬라이스로 검증 후 확장. 코어 재작성형 대공사는
  착수 전 표면화(제작자 확인).
- **재작성 위험**: 파생 수식/생성 로직 변경이 과거 세계를 소급 붕괴 → genVersion/frozen 동결.
- **AI 레이어 긴장**: 오프라인·결정론 코어와 AI(온라인)의 충돌 → 향신료 레이어로 격리, 폴백 필수.
- **비주얼 출시 격차**: 절차적/AI 마감은 스토어급 부적합 → 프로 에셋/외주(렌더 추상화로 교체 대비).
- **라이선스**: 가상 원칙 고수. IF 실명은 무료·가드레일 한정.
