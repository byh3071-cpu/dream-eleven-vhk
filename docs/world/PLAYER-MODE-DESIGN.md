# 선수 모드 설계 (Epic 2)

커스텀 유스 아바타를 15세부터 키워 1군을 꿰차고, 이적·국대·레전드까지 가는 "선수 인생" 모드.
제작자 결정 + 정찰(재활용 지도) + advisor 검증으로 확정. 상세 비전은 docs/PRD.md 선수 모드 여정.

## 확정 결정 (제작자)

- **기반**: 기존 커리어 4구단(B-first) — 정찰이 전부 커리어 save 기반이라 최저 마찰. world(39개국)
  포팅은 나중(성장 로직을 save-구조 독립으로 짜서 재배선만 하면 되게).
- **아바타**: 커스텀(이름·포지션 사용자 지정), 유스(15세)/기성 둘 다 선택. 대표 루트 = 유스 무명 15세.
- **훈련 = 친선/연습경기**(별도 훈련 슬라이더 화면 없음 — 친선 안에서 뭘 포커스할지).
- **범위 = 풀(이적·국대·서사)이되 슬라이스 단계**("한번에"를 2-1→2-2→2-3로, 2-1 먼저 보여주고 확장).

## ⭐ 콜드스타트 & 부트스트랩 루프 (설계의 척추 — advisor)

15세 아바타는 설계상 1군 레이팅 미달(그게 "무명→1군" 서사의 전제). 그런데:
- 리그 성장 채널은 `ratePlayers`가 XI(homeSquad11/awaySquad11)에 든 선수만 평가 → 유스는 XI 못 듦
  → seasonStats 미적립 → **뛰어야 성장, 성장해야 뛰는 데드락**.
- 선수 모드는 유저가 감독이 아니라 선수 → 리그 라인업에 자신을 **강제 못 넣음**(커리어 모드의 레버 상실).

**결론: 친선경기 = 1순위 부트스트랩 엔진, 리그 = 레이팅이 XI 바를 넘으면 언락되는 보상.**

```
친선(강제 선발·항상 가능) → 스탯↑ → 레이팅 pickBestXI 바 돌파 → 리그 출전(실력 획득)
  → 빠른 성장 + "1군 데뷔" 서사
```

**핵심 구현 요구**: 친선 매치 빌더는 아바타를 XI에 **강제 포함**(그 한 슬롯만 pickBestXI 우회).
친선이 pickBestXI를 그대로 쓰면 유스도 벤치 → 성장 0(설계 실패). 이 지점을 명시 검증.

## 재활용 지도 (정찰 — 신규는 "활약→성장" 한 곳 + frozen)

## frozen (developPlayer만 — advisor)

아바타는 경로의존(경기로 큰 값이 진실)이라 세이브에 눌러쓴다. developPlayer는 불변 base 전제로
매 조회 seasonsPassed만큼 성장/쇠퇴/나이를 다시 얹으므로 → **이중 계산**. 아바타는 developPlayer를
우회(frozen).
- **단 dampenPlayer(피로/폼)는 유지** — resolve 체인 전체를 얼리면 피로/폼 오버레이 + `.traits`
  보존까지 잃는다(정찰 부록 경고). frozen 범위 = developPlayer 한정.
- **우회 대가**: 나이 증가·30+/34+ 쇠퇴를 신규 코드가 명시 처리(안 하면 아바타가 안 늙고 안 꺾임).

## 성장 (shape-agnostic — world 포팅 대비)

- **공용 배분 헬퍼**: developPlayer 63-69(주+2/보조+1 배분)을 추출 → 시즌파생(NPC) + 활약(아바타)
  공유. "훈련 포커스"는 이 헬퍼의 `core` 가중치 인자(친선 안에서 선택).
- **성장 신호**: 친선 활약(부트스트랩) + 리그 활약(보상) → ratePlayers row → 배분 헬퍼.
- **save-구조 독립**: frozen 분기·배분 헬퍼·활약→성장 스텝을 커리어 save 구조에 안 묶기
  → 나중 world 포팅(A)이 재배선이지 재작성 아니게(39개국 무재작성 원칙 동일).

## 슬라이스 (풀은 단계로)

- **2-1 (첫 산출물 · DoD)**: 커스텀 아바타 생성+구단 소속 + **친선 부트스트랩 성장** + 리그 데뷔 +
  내 선수 시점 관전. **완료 판정: 서브-XI 15세가 친선으로 시즌 내 스탯 성장 → 결국 리그 경기에
  실력으로 등장.** (벤치 상태에서 성장 신호가 0이 아니면 루프 작동.)
- **2-2**: 특성 언락(마일스톤 트리거 → traits push) + 개인 이적/오퍼(bestSellOffer).
- **2-3**: 국가대표 + 개인 서사(press/story 전용).

크로스모드(선수→감독)는 Epic 3. world 포팅은 성장 로직 재배선으로.
