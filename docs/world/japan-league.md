# J 글로리 (일본 1부) — 구단 정체성

완전 공유 세계 Epic 1의 콘텐츠. **각 나라를 실제 리그 그대로 벤치마킹**(팀 수·운영·규칙),
껍데기(팀명·선수명)만 가상(라이선스 클린). 일본=J1리그처럼 **20팀**(더블 라운드로빈 38R),
한=12팀 / 영·스=각 20팀. 아래 확정 프로필이 그대로 게임 clubs 데이터가 된다(id/city/colors/
crest/stadium/supporters/nickname/concept/style/rivals). 리그명·팀명은 세이브 엔티티라 나중에
개성 리네임 가능(docs/DESIGN.md 데이터 원칙). J 글로리 특유 규칙 = **제휴국 선수 무제한(로컬
취급)** + **라이선스 게이트(적자 지속 시 승격 봉쇄)** + **골득실 우선** 타이브레이크
(docs/world/league-rules.md).

> **실지명 기반 · 라이선스 클린**: 실제 J1리그 20개 연고 **도시명은 그대로**(실지명은 상표 무관),
> **실팀명·마스코트·리그명은 전부 가상 애칭으로 대체**(우라와 레즈·감바 오사카·비셀 고베 등 실명 X).
> 실제 J1(2025 기준) 20개 연고 도시를 골격으로 하되, 요청(홋카이도 균형·사이타마 더비)을 반영해
> 2곳 큐레이션 교체 — 히라쓰카(쇼난)·오카야마 → **삿포로(홋카이도)·오미야(사이타마)**. 둘 다 실제
> J1 연고였던 도시라 실지명 원칙 유지. 큐레이션 시 되돌리기 쉬움.
