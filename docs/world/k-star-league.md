# K 스타리그 (한국 1부) — 구단 정체성

완전 공유 세계 Epic 1의 콘텐츠. **각 나라를 실제 리그 그대로 벤치마킹**(팀 수·운영·규칙),
껍데기(팀명·선수명)만 가상(라이선스 클린). 한국=K리그처럼 **12팀**(트리플 라운드로빈+스플릿),
일/영/스=각 20팀. 아래 확정 프로필이 그대로 게임 clubs 데이터가 된다(id/city/colors/crest/
stadium/supporters/nickname/concept/style/rivals). 리그명·팀명은 세이브 엔티티라 나중에 개성
리네임 가능(docs/DESIGN.md 데이터 원칙).
