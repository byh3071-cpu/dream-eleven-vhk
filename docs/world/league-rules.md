# 4개국 리그 규칙 세트

**원칙**: 각 나라를 실제 리그 그대로 벤치마킹(팀 수·운영·규칙), 껍데기(팀명·선수명·리그명)만
가상. 규칙·방식·팀 수는 저작권/상표 무관이라 자유 벤치마킹(docs 라이선스 판단). 4개 리그가
**실제 규칙대로 서로 다르게 굴러가는 게 핵심 재미** — 4개국 리서치(2026-07) 종합.

## 각 리그 특유 방식 (개성 = 재미)

- **K 스타리그(한) — 스플릿 + 다득점 우선**: 12팀이라 33R(트리플) 후 1~6위=파이널A / 7~12위=
  파이널B로 갈라 5R 더(승점 승계). 동점 시 **골득실보다 다득점을 먼저** 본다(공격 축구 유도).
  ✅ **스플릿 채택 확정**(사용자 결정) — 실제 K리그처럼 스플릿까지 재현. 구현 시 33R 후 중간
  재랭킹 → 파이널A(1~6위)/파이널B(7~12위) 분할 → 각 그룹 5R(승점 승계, 그룹 간 순위 고정)
  서브스케줄러를 신규 개발. **한국 리그만의 특유 방식**(다른 3개국은 단순 더블 라운드로빈).
- **J 글로리(일) — 제휴국 무제한 + 라이선스 게이트**: 동맹국 선수를 외국인으로 안 셈(로컬 취급).
  → 우리 4개국 "동맹 관계" 메커닉으로 번안(지역색). 재정은 캡이 아니라 "적자 지속 시 승격 봉쇄".
  승격 PO가 **단판·상위팀 홈·무승부 시 상위팀 진출**(결정론 엔진에 이상적 — 추첨 불필요).
- **E 프리미어(영) — 홈그로운 + PSR**: 25인 스쿼드 중 자국 육성 선수 최소 8명(유스 시스템 직결).
  재정은 3년 누적손실 한도(사후 규제). 승격 PO는 3~6위 → 준결승(2레그)+결승.
- **S 리가(스) — 승자승 우선 + 클럽별 샐러리캡**: 동점 시 맞대결 우선(잉글랜드 골득실과 반대).
  재정은 **등록 차단형 사전 캡**(클럽별 수입기반 한도 — 초과 시 영입 등록 불가).

## 대륙컵 "글로리 컵" (4개국 크로스)

각국 상위팀이 겨루는 메타 대회 = 4개국 리그를 하나로 묶는 최상위 목표(챔스/ACL 아날로그).
- **진출**: 각국 1부 상위 N팀(예: 1~2위 챔피언급 / 3~4위 유로파급) + 컵 우승자.
- **포맷(리서치 권장)**: 참가팀 적으면 UEFA 스위스는 과잉 → **더블 라운드로빈 리그페이즈 → 상위
  결승 하이브리드**(서클메서드 엔진 재사용 100%). 참가 16팀+로 커지면 스위스 검토.

## 우리 엔진 구현 원칙 (결정론 유지)

- **팀 수 = 짝수 유지**: 서클메서드(generateFixtures)는 짝수 전제. 실제 하부가 홀수여도(K2=17
  등) 우리는 전 디비전 짝수로 정규화(바이 없이 바닐라 엔진).
- **라운드 = rounds 옵션**: 12팀 트리플=rounds:3(33R), 20팀 더블=rounds:2(38R). 이미 지원(코드 0).
- **타이브레이크 최종키 = 결정론**: 실제 규칙 마지막 단계(추첨·중립 플레이오프·공동우승)는
  결정론과 모순 → **팀 시드/id 고정 순서로 치환**(같은 입력 = 같은 순위). 리그별 앞단(다득점/
  골득실/승자승)은 실제대로 분기.
- **이적창 = 라운드 기준**: 캘린더 대신 "R1 전 여름창 / R19~20 겨울창" 식 고정(결정론 간단).
- **재정 = 비율캡 우선**: K리그식 "선수비용 ≤ 수입 N%"가 절대금액 캡보다 우수(규모 자동 스케일·
  리그별 하드코딩 불필요). 국가별 N·방식 차등이 곧 리그 개성. 유스 투자는 면제 옵션.
- **승강 = 3↓3↑ 표준**(한국만 다단계 PO). 최상단=승격없음/최하단=강등없음(또는 신생팀 주입)
  명시. 인접 디비전 승격 PO는 J리그식 "단판·상위팀 홈·무승부시 상위진출"이 결정론에 이상적.

## 구현 순서 (C 단계)
1. clubs/leagues 세이브 엔티티(현 CLUBS 상수 대체) + 12/20팀 로스터 생성기.
2. 리그별 규칙 파라미터(팀수·rounds·타이브레이크·외국인캡·재정캡·승강수)를 데이터로.
3. generateFixtures 리그별 호출 + 순위/승강 로직 + 결정론 타이브레이크.
4. **한국 스플릿(채택)** + (선택) 대륙컵 / 홈그로운·제휴국 등 리그 개성 레이어.
