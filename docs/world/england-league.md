# E 프리미어 (영국 1부) — 구단 정체성

완전 공유 세계 Epic 1의 콘텐츠. **각 나라를 실제 리그 그대로 벤치마킹**(팀 수·운영·규칙),
껍데기(팀명·선수명)만 가상(라이선스 클린). 잉글랜드=프리미어리그처럼 **20팀**(더블 라운드로빈
38라운드). 아래 확정 프로필이 그대로 게임 clubs 데이터가 된다(id/city/colors/crest/stadium/
supporters/nickname/concept/style/rivals). 리그명·팀명은 세이브 엔티티라 나중에 개성 리네임
가능(docs/DESIGN.md 데이터 원칙).

**라이선스 원칙**: 실제 잉글랜드 **연고 도시·행정구명은 그대로 사용**(런던 각 구·맨체스터·
리버풀·뉴캐슬 등). 하지만 **실제 구단명·리그명·공식 별명은 전부 가상 애칭으로 치환**
(맨체스터 유나이티드/시티·리버풀·아스날·첼시·토트넘 등 실명 금지). 리그명은 "E 프리미어" 확정.
잉글랜드 축구 특유의 톤 — **전통 접미**(United·City·Rovers·Wanderers·Albion·Athletic·
Town·County)와 **개념·직업·상징어**를 섞어 20팀을 짓되, 각 도시의 실제 특색(항구·탄광·제철·
양조·대학·해변)을 정체성에 새긴다.
