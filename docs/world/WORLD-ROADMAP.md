# 월드 리그 시스템 — 로드맵 & 세션 인계

이 문서 하나로 월드 리그 작업을 이어받을 수 있게 정리한다. 비전·콘텐츠·아키텍처·진행·다음
단계·열린 결정을 담는다. 상세는 각 참조 문서로.

## 1. 비전 (확정)

**3-모드가 하나의 공유 세계를 본다** — "축구 인생 시뮬"(액션이 아니라 전략·서사·관전).
- **IF (神 시점)**: 레전드 드림매치. 기존 재미요소 — **그대로 두고 안 건드림**.
- **커리어 (팀 시점)**: 구단 감독. → 39개국 월드 리그의 감독.
- **선수 (개인 시점)**: 선수 '나'의 인생(유스→스타→레전드→감독). 신규(Epic 2).
- **크로스모드**: 선수모드로 키운 '나'가 감독모드 이적시장·상대팀에 영구 등장(Epic 3).

## 2. 세계 콘텐츠 (확정)

**39개국 = 4개국 플래그십(수작업) + 35개국 생성기.**
- **플래그십 84팀**(수작업 정체성, 색·상징·별명·서포터즈·홈구장·라이벌·스타일 전부):
  - 🇰🇷 K 스타리그 **12팀** — docs/world/k-star-league.md (서울 제네시스~제주 옵시디언)
  - 🇯🇵 J 글로리 **20팀** — docs/world/japan-league.md
  - 🏴 E 프리미어 **20팀** — docs/world/england-league.md
  - 🇪🇸 S 리가 **20팀** — docs/world/spain-league.md
- **35개국 생성기**(국가 프로필 → 팀·선수 프로시저럴, 유명 리그는 나중에 플래그십 승격):
  프랑스·독일·이탈리아·포르투갈·브라질·아르헨티나·튀르키예·러시아·벨기에·네덜란드·모로코·
  미국·호주·이집트·크로아티아·콜롬비아·멕시코·사우디아라비아·세네갈·스위스·이란·에콰도르·
  오스트리아·캐나다·노르웨이·코트디부아르·파나마·스웨덴·체코·파라과이·스코틀랜드·튀니지·
  카타르·중국·베트남.
- **각 리그 실제 운영/규칙 벤치마킹**(팀수·라운드·승강·타이브레이크·외국인·이적창·재정·
  대륙컵) — docs/world/league-rules.md. 35개국도 확장 시 리서치 반영.

**라이선스**: 규칙·운영·팀수는 벤치마킹 자유(저작권/상표 무관). 실 도시명 OK, 팀명·리그명·
선수명은 전부 가상. IF 레전드만 무료 단계 실명+가드레일, 수익화 시 가상명(별도 정책).

## 3. 아키텍처 (확정 + 원칙)

- **world 모듈(src/world/) = additive**: 기존 커리어(src/career, 4구단 드래프트)·IF와 완전
  별도. 4팀→84팀 마이그레이션 없음, 돌아가는 게임 보호(advisor 권고). 세이브도 신규 타입.
- **무제한 나라 = 데이터 주도**: `src/world/leagues.js` 배열에 리그를 데이터로(팀수·rounds·
  타이브레이크·규칙). **나라 추가 = 배열 항목 추가(코드 재작성 0 = 갈아엎기 없음)**.
- **생성기**: youthGen 확장(국가 프로필: 리그명·도시풀·강도·스타일 → 팀·선수). 결정론 유지.
- **designLint 예외**: src/world/data/는 구단 색=콘텐츠 데이터(UI 토큰 아님)라 hex 허용.
- **재작성 방지(docs/DESIGN.md ADR)**: 파생 수식 분기/stateful producer는 **같은 커밋에
  가드 필드**(genVersion/frozen) — 미리 심지 말 것. 결정론 타이브레이크 최종키는 추첨→시드.
- **렌더 추상화(ADR)**: 3D 캐릭터를 CharacterFactory/모션 파라미터/앵커 뒤에 → 비주얼 교체
  (glTF/Synty/AI)가 부품 갈이(Epic 4). 얼굴 디테일은 인게임 원경에 안 보이니 클로즈업 전용.

## 4. 진행 상황 (C = 구현)

- ✅ **C-1 골격** (커밋 8dfa586): leagues.js(무제한 나라 데이터 구조) + korea.js(12팀) +

- ▶ **C-2 (다음)**: 로스터 생성(youthGen 재활용, 12팀 × 선수) + 매치 시뮬 + 순위표 =

  완성 지점 → 여기서 "39개국 확장 ㄱㄱ" 판단.
- ⬜ **C-3**: 39개국 확장 — 국가 프로필 + generateYouth 일반화(국가→리그→로스터).
- ⬜ **C-4**: 리그 개성 레이어 — 한국 스플릿(파이널A/B, 채택 확정), 대륙컵 "글로리 컵"

- ⬜ **C-5**: 월드 세이브(신규 타입) + UI(리그 화면·순위표·이적창).
- ⬜ **Epic 2 선수 모드 / Epic 3 크로스모드 / Epic 4 비주얼 마감 / Epic 5 출시(PWA·스토어)**.

## 5. 열린 결정 / 아이디어 (미확정)

- **선수 모드**(Epic 2): 시작=유스+가상기성 둘 다. 성장=훈련 포커스+평점+특성 언락. 경기=
  경기 전 지시+내 선수 시점 관전(실시간 조작 X — 사전계산 엔진 정합). FM 재미=이적/오퍼/
  언론/스캔들/부상/슬럼프/국가대표/라이벌/멘토링/팬덤/계약드라마/시그니처 각인/**선수→감독
  전환**(공유 세계 화룡점정). 재활용: developPlayer/ratePlayers/traits/bestSellOffer/press·
  story/awards(정찰 완료 — 진짜 신규는 아바타 세이브 슬롯·활약→성장 연결선·특성언락 트리거·
  관전/국대 UI 4개뿐).
- **비주얼**(Epic 4): 아트 스타일 확정(고유 스타일라이즈드 권장) + 캐릭터(절차적→Synty/AI/
  외주). 스팀/앱스토어 출시급은 AI 생성 마감 부적합(후처리·정책) — 프로 에셋/외주가 정답.
- **35개국 승격**: 유명 리그(프랑스·독일·이탈리아 등)는 나중에 플래그십처럼 깊이.
- **한국 스플릿 구현**: 33R 후 중간 재랭킹→파이널A/B 분할→5R(승점 승계) 서브스케줄러.
