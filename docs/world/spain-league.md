# S 리가 (스페인 1부) — 구단 정체성

완전 공유 세계 Epic 1의 콘텐츠. **각 나라를 실제 리그 그대로 벤치마킹**(팀 수·운영·규칙),
껍데기(팀명·선수명)만 가상(라이선스 클린). 스페인=라리가처럼 **20팀**(더블 라운드로빈 38R,
스플릿 없음), 한국=12팀, 일/영=각 20팀. 아래 확정 프로필이 그대로 게임 clubs 데이터가 된다
(id/city/colors/crest/stadium/supporters/nickname/concept/style/rivals). 리그명·팀명은 세이브
엔티티라 나중에 개성 리네임 가능(docs/DESIGN.md 데이터 원칙).

> **라이선스 규약**: 실제 **연고 도시명은 사용**(마드리드·바르셀로나·세비야·빌바오·비고…).
> 실제 **구단명·리그명은 전부 가상 애칭으로 회피** — 레알 마드리드·바르셀로나·아틀레티코·
> 세비야·베티스·소시에다드·셀타·오사수나·마요르카 등 실명 미사용. 두 클럽이 한 도시를
> 공유하는 세비야(네르비온/트리아나)·발렌시아(박쥐/개구리)는 **실 지구(地區)·시 상징**으로 분리.
> "Real/Atlético/Deportivo" 접두는 스페인 축구 공통 관용이라 사용하되, 도시+접두가 실제
> 구단명이 되지 않게 조합. 리그명은 **"S 리가"**(확정).

> **문서 구조**: k-star-league.md와 동일한 팀별 필드 스키마(id/연고지/컨셉/이름 유래/색/상징/
> 홈구장/서포터즈/별명/스타일/라이벌). 20팀이라 **지역 6블록**으로 묶어 지역 정체성·더비를 노출.

**더비 재현 (라리가 4대 더비를 가상팀으로)**:
- **마드리드 더비 (El Derbi madrileño)**: 레알 시벨레스 ↔ 아틀레티코 오소 (+ 헤타페 ↔ 바예카스 남부 더비)
- **엘 클라시코 (El Clásico)**: 레알 시벨레스 ↔ 카탈라 그라나 (카스티야 왕관 vs 카탈루냐 독립혼)
- **바르셀로나 / 카탈루냐 더비**: 카탈라 그라나 ↔ 코르네야 코토라 (독립 vs 통합) · + 지로나 무랄라
- **바스크 더비 (El Derbi vasco)**: 빌바오 레온 ↔ 레알 도노스티아 ↔ 데포르티보 비토리아 (+ 팜플로나 북부)
- **세비야 더비 (El Gran Derbi)**: 네르비온 CF ↔ 레알 트리아나 (승부 vs 낭만, 과달키비르 강 사이)
- **발렌시아 더비**: 무르시엘라고 CF ↔ CD 그라노타 (박쥐 vs 개구리, + 비야레알·엘체 지방 더비)
